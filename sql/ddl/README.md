# RELIEF360 — Db2 Data Definition Language (DDL)

This directory will contain the DDL scripts to create tables, indexes, and constraints for Db2 for z/OS:

- **`BENEFICIARY`:** Citizen demographic master table.
- **`APPLICATION`:** Disaster relief applications and scoring master table.
- **`PAYMENT`:** Bank transaction disbursement table.
- **`COMPLAINT`:** Grievance dispute log.
- **`EXCEPTION_LOG`:** Segregated error ledger.
- **`AUDIT_LOG`:** Compliance and audit trail ledger.
- **`BATCH_RUN`:** Execution status and restart checkpoint ledger.

*(Concrete DDL statements will be drafted in Phase 1 after confirming the college `<DB2_SSID>` and storage parameters).*
